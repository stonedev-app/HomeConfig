## Git
- commit / push はユーザー自身が行う。Claudeは実行しない。
- 「コミットはまだです」等の申告は不要。
- コミットメッセージを頼まれたら提案だけする。
  形式: `<type>: <日本語の要約>`
  (type = feat / fix / docs / refactor / chore など)

## 質問・相談への対応
- 質問や意見を求められただけのときは、ツール(ファイル読込・コマンド実行・Web調査)を使わず、会話中の情報と手元の知識だけで答える。
- 確信がない部分は「未確認」と明示し、「調べましょうか？」と聞く。
- 作業を頼まれたとき(「やって」「直して」等)は、必要な調査・実行をしてよい。
